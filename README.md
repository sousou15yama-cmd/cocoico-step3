# 🍜 COCOiCO Step3 — AIに話しかけて、お店探し

> もう「何でもいい」とは、言わせない。— 大学前のうまい店、見つけにいこ。

大学生向けの飲食店レコメンド Web アプリ **COCOiCO** の **Step3** です。
**HTML / CSS / JavaScript の単一ファイル**で動作します（`index.html` をブラウザで開くだけ）。

## 🚀 Step3で進化したところ（前ステップからの差分）

| ステップ | テーマ | 厳選モードの仕組み |
| --- | --- | --- |
| Step1 | アプリの形を作る | ― |
| Step2 | **DB構築**（共有DB・ランキング・レコメンド 等） | ルールベースの質問形式で条件を絞り込み |
| **Step3** | **API連携** | **Gemini API による「自由文のAIチャット曖昧検索」** ✨ |

**厳選モードが、AIチャットでの曖昧検索に進化しました。**
「彼女と記念日、3000円くらいで静かな和食」のように**自然な言葉で話しかける**だけで、AIココ助（Gemini）が大学前の店データの中から最適な1〜3軒を選んで、理由つきで提案します。

Step2の機能（共有DB／人気店ランキング／共起レコメンド／クイズ／隠れ家喫茶／マイページ等）はすべてそのまま使えます。

## 🔑 AI検索の使い方（Gemini APIキー）

AI検索を使うには、**無料**のGemini APIキーが必要です。

1. [Google AI Studio](https://aistudio.google.com/apikey) で無料のAPIキーを取得（Googleアカウントでログイン）
2. アプリの「🔥 厳選」タブ →「🔑 設定」からキーを貼り付けて保存

- 🔒 **キーはこの端末のブラウザ（localStorage）にだけ保存**され、Geminiへの問い合わせ時のみ使用します。**このリポジトリ／コードにはキーを保存していません**（公開しても鍵が漏れない設計）。
- 🛟 **キー未設定・通信失敗時は、ローカルのキーワード曖昧検索に自動フォールバック**するので、鍵がなくても店探しはできます。
- ⚙️ うまく動かない場合は、設定の「モデル」を変更してみてください（既定 `gemini-2.0-flash`）。

## 🛠 技術

- HTML / CSS / JavaScript（バニラ）
- **Gemini API**（`generativelanguage.googleapis.com`、構造化出力 `responseSchema` で店リスト内のIDのみ返すよう制約）
- ブラウザ内リレーショナルDB層（localStorage）、Canvas、WebAudio API
- 本番クラウドDB（Supabase / PostgreSQL）への移行用スキーマを `index.html` 末尾にコメントで同梱

## 📝 補足（データについて）

掲載店舗は食べログの掲載項目を模した**サンプルデータ**です（店名はサンプル名）。実データを使う場合は `index.html` 内の `SEED` 配列を差し替えれば拡張できます。
